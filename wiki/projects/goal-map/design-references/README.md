# Goal Map — Design references

Images and notes for the design session. Drop images into this folder. Note that the vault is pushed to GitHub, so only add images that are fine to publish. Back to the [hub](../overview.md).

## Direction

The direction is shifting toward an epic voyage with tension (the *Odyssey*, Jules Verne engravings), away from calm and cozy. It's still in progress; see the [decision](<../../../decisions/decision-log.md#2026-10-03 — Goal Map: design direction shifting toward an epic voyage with tension>). The brief allows references as inspiration for a feeling, never names, places, lettering or art lifted from them.
