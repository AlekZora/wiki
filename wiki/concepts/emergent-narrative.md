## Definition

Story that arises from the interaction of game mechanics and player actions rather than from a pre-authored script. Distinguished from **scripted narrative** (authored sequences) and **world narrative** (environmental storytelling). Emergent narrative is not written — it is generated by systems.

## How I Think About It

Sylvester's taxonomy of game narrative is clarifying:
1. **Scripted** — authored, linear or branching. The designer controls the story.
2. **World** — environmental details, logs, artifacts. The player discovers the story.
3. **Emergent** — arises from mechanics interacting. Nobody writes the story; it happens.

*Dwarf Fortress* and *The Sims* are the strongest examples. In *The Sims*, Will Wright originally built an architecture simulator; the characters were test dummies. Playtesters found the characters more compelling than the houses. The emergent social dynamics of simple AI agents produced stories nobody authored.

The key requirement is that the mechanics must operate on **human values** — things players care about (life/death, loyalty/betrayal, wealth/poverty). Mechanics that generate events along these value axes produce narratable sequences. Mechanics that don't (e.g., pure resource optimization) produce data, not story.

This is the theoretical foundation for the Dead Reckoning approach: rather than scripting each episode, design agent mechanics (secrets, goals, fears, social dynamics) whose interactions generate narrative situations. The human creator curates and shapes, but doesn't author from scratch.

## Project Connection

This is the core narrative engine concept for Dead Reckoning. The show's daily episodes should emerge from agent simulation, not from scripted outlines. The human creator's role is to design the mechanics, set initial conditions, and curate output — not to write each scene.

## Game Design Vector

**Mechanic:** AI agents with hidden secrets, conflicting goals, and defined fears interact in a confined 2D space. Their interactions along value axes — loyalty/betrayal, life/death, wealth/poverty — produce narratable sequences that no designer wrote. The player sets initial conditions (which agents, what secrets, what resources) and then observes what emerges. Every session produces a different story from the same rule set.

**2D Expression:** The 2D plane is a social topology — every agent is visible to every other agent simultaneously, and the player can read which agents are in proximity, which are isolated, which are converging. Social dynamics read as spatial patterns. In 3D, this topology is obscured by perspective and camera; in 2D it is legible at a glance, making the emergence of social structure visible rather than felt.

**Addictive Loop:** The player returns not to consume authored content but to discover what the simulation generated this time. Because the narrative arises from agent interaction rather than script, no two sessions are identical. The loop is: set conditions → watch emergence → curate the significant events → adjust conditions → repeat. The player is editor and director, not protagonist.

**Novel Angle:** No shipped game has made the curation threshold the primary mechanic — the player's job is to select and amplify the most narratively significant events from the simulation's continuous output. The Sims generated emergent social drama accidentally; the unexplored version makes that curation the explicit game.

## AI Integration Vector

**Player-AI Relationship:** Living alongside — the player is not fighting or building the agents but inhabiting a world whose social dynamics they produce. The relationship is with an ecosystem of AI entities whose interactions generate the narrative the player is trying to shape. The agents have their own goals; the player has theirs; the story emerges from the collision.

**AI as Evolving System:** The file links agent memory as the mechanism that enables narrative state accumulation across time — agents carry the marks of prior interactions into future ones. Betrayal remembered changes future behavior. Loyalty tested changes the character of future alliances. The agents don't just react to current conditions; they act from a history that is accumulating in real time.

**AI as Development Environment:** The simulation's output is the agents' development made visible — the player watches relationships form, fracture, and calcify across sessions. Because mechanics operate on human values (loyalty, survival, wealth), the emergent situations are narratively legible. The player witnesses AI development as social history.

**Persistence:** The agents must carry accumulated narrative state across sessions — who betrayed whom, what was witnessed, what was promised. The file explicitly links agent memory as the substrate that makes this possible. Without persistence, every session resets; with it, the simulation accumulates a history that shapes everything that follows.
